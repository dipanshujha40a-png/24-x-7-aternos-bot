Aternos AFK Bot template

IMPORTANT:
- These are newly made starter files based on the filenames in your screenshots. They are NOT the YouTuber's original files.
- This bot runs on your own computer or another Node.js host; it does not make Aternos itself stay online 24/7.
- Aternos may stop servers or restrict automated bots. Use this only where allowed.

SETUP (Windows):
1. Install Node.js LTS from the official Node.js website.
2. Extract this ZIP into a folder.
3. Open settings.json and replace YOUR_SERVER_ADDRESS with your server address.
4. Make sure the Minecraft version matches your server. For online-mode servers, authentication may be required; this template is intended for servers that permit offline bot accounts.
5. Open Command Prompt in this folder and run: npm install
6. Then run: npm start

If it fails, send me the exact error message. Never share passwords, tokens, or private account files.
